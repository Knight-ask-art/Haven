# Reference

Reference material is compact and lookup-oriented. It may point to generated
contracts, command manifests, terminology or test fixtures, but it must not
become a second hand-maintained copy of those sources.

Generated references must identify their generator and source. Hand-edits to
generated IPC output are forbidden; update the Rust source and run the
repository generator instead.
