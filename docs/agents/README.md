# Engineering Agents

Agents are bounded workers inside a user-authorized task. They do not own
product truth, merge authority, release approval or cleanup authority.

## Start here

- [Claude Code Subagent Protocol](claude-code.md)
- [Engineering Agent Roles](engineering-agents.md)
- [Agent Handoff Template](handoff.md)

Every delegation names its objective, allowed paths, forbidden paths,
acceptance, tests and evidence. The main agent independently reviews the diff
and validation result.
