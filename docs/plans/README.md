# Planning Documentation Policy

Public proposals belong in an issue or a focused architecture/design document
and must be labeled as proposals. They do not establish shipped capability.

Private execution plans and their filenames are not part of public navigation.
Preserve historical originals privately; publish only accepted, revalidated
decisions in the appropriate canonical document.

See [Engineering Change Workflow](../TASK_WORKFLOW.md),
[Documentation Migration](../engineering/documentation-migration.md) and
[Architecture Decisions](../decisions/README.md).
