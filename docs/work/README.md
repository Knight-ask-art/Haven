# Public Work Status

GitHub Issues describe proposed changes and discussion. Pull requests describe
the scoped implementation, review and CI results for a particular head commit.
Release notes describe delivered behavior.

These surfaces are not proof of interactive desktop behavior or a substitute
for the product's contracts and capability Registry. See
[Testing and Evidence](../engineering/testing-and-evidence.md).

Public descriptions should include the purpose, affected behavior and completed
validation relevant to contributors and users. Private task ledgers,
development-tool coordination and raw operational records are not reproduced
here.
