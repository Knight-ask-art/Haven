# Design

Design documents describe presentation and interaction for capabilities that
already exist or are explicitly marked as planned. A mock, screenshot or Figma
frame cannot establish a backend capability.

Keep the current visual design when connecting real data. Loading, empty,
partial, offline, disabled and error states should be designed explicitly and
should match the Feature Registry status.
